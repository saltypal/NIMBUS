# ShiftOver Motors demo context

ShiftOver Motors and the Northstar Demonstration Plant are fictional. Their machines, vehicles, parts, people, readings, faults, work records, and verification evidence exist only for a software demonstration.

## Observation language

Record what the fictional operator observed separately from context, impact, suspected cause, and proposed action. A suspected cause is not a measured root cause. A proposed action is not proof that work occurred.

## Ticket context

Vehicle ID, part name, and production stage provide product context for filtering and handover. They do not change ticket status. Status changes only through reviewed workflow actions and the approved synthetic verification rule.
